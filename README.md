# MONARCA.PARIS

Сайт магазина аксессуаров для волос: крабы, заколки-бабочки, гребни.

- Первый экран — летний Париж; вывеска MONARCA проходит за головой девушки.
- При прокрутке фото растворяется, и бордовая заколка собирается из деталей (193 кадра на canvas).
- Коллекция из 14 товаров с фильтрами, карточка товара, корзина и форма заказа.

Сайт статический: HTML, CSS и JavaScript без сборки.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
node server.mjs
```

и откройте http://localhost:4322.

## Где что менять

| Что | Где |
| --- | --- |
| Товары, цены, описания | `js/products.js` |
| Фото товаров | `assets/products/` |
| Отправка заказов (сейчас только `console.info`) | функция `sendOrder` в `js/main.js` |
| Ссылки на соцсети в подвале | `index.html` |
| Цвета и шрифты | переменные в начале `css/style.css` |

Цены в `js/products.js` пока ориентировочные.

## Структура

```
index.html
css/style.css
js/products.js      каталог
js/main.js          сцена со скроллом, каталог, корзина
assets/frames/      кадры сборки заколки (1600 px)
assets/frames-sm/   те же кадры для телефонов (960 px)
assets/hero/        фото первого экрана и вырезка девушки
assets/products/    фото товаров
server.mjs          простой локальный сервер
```
